# Template: Twitter/X thread

Structure to follow when drafting:
- Tweet 1 (hook): one bold claim or counterintuitive promise. No "a thread 🧵" filler.
- Tweets 2–N: one idea per tweet, ≤280 chars, each able to stand alone.
- Use concrete numbers and examples over adjectives.
- Penultimate tweet: the synthesis / "so what".
- Final tweet: CTA (follow / reply / link).

Voice: punchy, declarative.
